# Watch6 录音 0.5.0：表盘＋通信快应用

单 BIN 经运动健康自行登记身份的入口尚未验证通过。本版按用户授权采用
表盘＋通信快应用的方案，使用原来的 MiFitness / uv_miwear 传输路径。
通信快应用只需安装，日常不必打开；录音与回听始终从录音表盘操作。

## 三个安装文件

| 安装位置 | 文件 | 职责 |
|---|---|---|
| 手机 | `Watch6-Recorder-Phone-0.5.0.apk` | 后台接收、完整保存、手机回听、分享与另存下载 |
| 手表表盘 | `Watch6-Recorder-0.5.0.bin` | 离线录音、暂停继续、保存、完整回听与发起导出 |
| 手表快应用 | `Watch6-Recorder-Identity-0.5.0.rpk` | 提供本项目的运动健康通信身份；不录音、不加载原生模块 |

手机和快应用包名均为 `com.watch6.recorder`，使用同一证书。
手机版本号 7、快应用版本号 6，可更新本项目的旧版本；不使用 VoiceSpace 的
包名或签名，不覆盖其项目，也不自动删除录音。

## 首次设置

1. 确保小米运动健康已配对 Watch 6。手表需满足源码兼容矩阵中的精确固件指纹。
2. 在手机文件管理中打开 APK 安装；BIN 是表盘文件，RPK 是手表快应用文件，需用你的手表导入工具分别导入。它们不能作为手机 APK 安装，也不能互相替代。使用此前成功导入本项目的同一工具和入口即可；本包不捆绑第三方侧载工具，也不声称运动健康商店已上架。
3. 手机打开「Watch6 录音」，点「开启接收」，允许附近设备、通知和运动健康通信。
4. 手机显示「接收已待命」代表监听准备完成；收到有效录音协议后
   才显示实际通信，不能把仅监听安装成功当作手表已回执。
5. 需要手机息屏接收时，允许运动健康和本应用自启动、后台运行。系统强制停止
   或撤销权限后仍需恢复设置；正常使用不要求每天重开快应用。

如果之前安装过独立 BLE 实验表盘，应先结束录音、保留文件，再完整重启手表。
新包不会强制卸载仍持有回调或源文件的旧模块。

## 日常使用

1. 只打开录音表盘，点开始；确认进入录音后计时。手机不在附近也能录音与回听。
2. 同一条录音支持暂停、继续、结束保存。保存完成即可准备下一条，不等字幕。
3. 选择完整录音回听，可暂停、继续、停止；手动停止不显示「已完整播完」。
4. 点「发送到手机」。确认源文件完整后，经运动健康发送到手机；途中断开可续传。
5. 手机完整落盘并校验后才确认成功。可在手机回听、分享或保存到 Download/Watch6Recorder。
6. 手机关闭接收会立即使旧会话失效。已保存的进度和原音保留，旧队列不能串入新会话。

## 本版实质改动

- 手机区分监听已安装与实际协议通信；首次授权意图不被后台重试反复使用。
- 接收关闭、服务重建、旧 SDK 回调均进行会话校验；队列执行和 ACK 提交分别检查。
- 保留有界队列、分片／全文件校验、持久化检查点、尾音和缓存所有权保护。
- 新增从空归档开始的连续工作流模拟：实际 ARM 采音落盘、暂停继续、完整播放、
  停止、导出和 JVM 持久化 ACK；不预填一条“已保存录音”或现成 WAV 冒充成功。

## 验证边界

主机模拟使用明确的合成采音、系统和 SDK 边界，不代表真实麦克风、扬声器或
运动健康射频已经通过。当前用户暂不方便连接设备，代码和安装包先交付；
真实录音尾音、完整回听、手机息屏、断线恢复和吞吐仍需之后实机验收。
本版不会把这些待验项写成已经通过。
