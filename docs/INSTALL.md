**[一键下载完整安装合集](https://github.com/qianliji/watch6-recorder/releases/download/v0.5.3/Watch6-Recorder-0.5.3-Install.zip)**

本版配套组合为：**表盘 0.5.3 + 手机 App 0.5.1 + 连接组件 0.5.0**。三者版本号不同是正常的，请使用同一发布页提供的组合。

## 先确认设备

- 手表：REDMI Watch 6 / P65 / 3.100.043，且内置固件指纹校验通过。其他型号或固件不在本安装包支持范围内。
- 手机：Android 12 或以上，已安装小米运动健康，并与这块手表正常配对。
- 自行准备「表盘自定义工具」，用于把 BIN 与 RPK 安装到手表。本项目不提供该工具。

## 第一次安装

1. **安装手机 App。** 在手机下载并点开 `Watch6-Recorder-Phone-0.5.1.apk`，安装「Watch6 录音」。按手机系统提示完成安装。
2. **安装连接组件。** 在「表盘自定义工具」中选择自己的 Watch 6，用快应用安装入口导入 `Watch6-Recorder-Identity-0.5.0.rpk`，等待安装完成。它在手表中名为「录音连接组件」，安装后保留即可，日常不用打开。
3. **安装并启用表盘。** 用同一工具的表盘安装入口导入 `Watch6-Recorder-0.5.3.bin`，完成后在手表切换到这张录音表盘。
4. **恢复日常连接。** 安装工具用完后，回到小米运动健康，确认手表显示已连接。后续无线导出使用小米运动健康链路，不需要让安装工具一直连接。
5. **开启手机接收。** 打开「Watch6 录音」，点底部「连接」→「开启接收」，按提示允许附近设备、通知及小米运动健康通信授权。
6. **做一次短录音。** 手表点「开始录音」，正式计时后说约 10 秒，再点「结束并保存」。保存完成后，可点「完整回听」检查声音，再点「发送到手机」。手机完成接收与保存后，录音会出现在「我的录音」。

日常录音、回听和发送都在录音表盘内操作，不必每次打开连接组件。不需要连接 USB，也不用填写 API 密钥、服务器地址或电脑配对码。

## 日常怎么用

- **录音：** 点「开始录音」，等准备完成进入计时；录制中可暂停、继续，结束后保存。
- **手表回听：** 保存后点「完整回听」；查看旧录音时，点「录音列表」选择对应记录。页面通过点击进入，不需要滑动找按钮。
- **发送到手机：** 选择已保存的录音，点「发送到手机」。手机接收完成并校验保存后，可以播放、拖动进度、保存到下载文件夹或手动分享。
- **继续录下一条：** 保存后点「准备下一条」，回到待录状态，再点「开始录音」才会录制。
- **离线使用：** 手机不在附近时，手表仍可录音与本地回听；之后连接手机再发送。发送成功不会自动删除手表原音。

## 手机息屏时接收

先完成一次「开启接收」及通信授权，再按手机系统设置允许「Watch6 录音」和「小米运动健康」自启动、后台运行。小米／红米手机可将两者设为省电「无限制」，需要时锁定后台。

不要在系统中强行停止这两个应用。系统重启或应用更新后会尝试恢复已开启的接收；若被系统限制、撤销权限或主动关闭接收，需要重新开启。后台是否稳定仍受手机系统和蓝牙状态影响。

## 常见问题

| 情况 | 怎么处理 |
| --- | --- |
| 为什么手表还要安装 RPK？ | BIN 负责录音和回听；RPK 提供运动健康通信身份，用于无线导出。只需安装保留，日常不用进入组件。 |
| 表盘显示等待手机连接 | 检查运动健康是否连接、RPK 是否已安装、手机 App 是否已开启接收并完成授权。安装后不要让安装工具一直占用连接。 |
| 手机显示接收已待命 | 表示接收已开启；收到表盘有效通信后才会显示已连接手表。 |
| 接收到了 100%，但还不能播放 | 字节已收齐，还需完成校验与保存。若出现「完成保存」，点它重试保存，不必重新录音。 |
| 传到一半断开了 | 保留原音，恢复连接后从手表发送同一条录音，继续接收。 |
| 手机提示签名冲突，不能更新 | 使用本发布页匹配的 APK 与 RPK；自建版本需用自己的同一证书。已有录音时先导出备份，不要为排错直接卸载。 |
| 提示固件不支持 | 当前包只适配上述精确固件；保留兼容性保护，等待适配对应固件的版本。 |

## 校验与更新

发布页提供 `SHA256SUMS.txt`，完整合集内也提供三份安装包的 SHA-256 校验值。更新时先结束并保存录音，再安装新包。当前从 0.5.0 升级，只需更新 BIN 和 APK；已安装的 0.5.0 连接组件继续保留。
