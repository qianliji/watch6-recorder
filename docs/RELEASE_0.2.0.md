# 0.2.0-preview 交付与验收

本次只更新独立 Watch6 Recorder 工程。原 VoiceSpace 手机、表盘、电脑与云端运行项目没有因本次开发而替换。旧 0.1.0 产物保留。

## 安装组成

- `Watch6-Recorder-0.2.0-preview.bin`：手表离线录音、暂停/继续、结束保存、录音列表、完整回听。
- `Watch6-Recorder-Phone-0.2.0-preview.apk`：手机无线接收、完整回听、进度拖动、分享、保存下载。
- `Watch6-Recorder-Identity-0.2.0-preview.rpk`：无线导出的运动健康身份组件，与手机伴侣同包同签名。首次需安装并授权，日常不必打开。

离线录音和手表回听只需表盘。无线导出还需手机伴侣、身份组件和运动健康已配对连接；原 VoiceSpace 身份不能复用。首次授权必须由用户在手机完成。设备仅适配 COMPATIBILITY 中列出的精确 P65 固件，不对其他版本强行加载。

## 日常操作

打开表盘 → 开始录音 → 等正式计时 → 可暂停/继续 → 结束并保存。保存和原生退出确认后即可准备下一条，不等待字幕或手机。

完整回听：保存后点「完整回听」，或在录音列表点选一条。准备阶段校验所有源分段及尾音，生成一条 WAV，再连续播放。可暂停、继续或停止；中途停止不会显示“已完整播完”。正在回听时点击顶部状态可回到该条控制页。切换录音会先安全关闭回听，不同时占用扬声器采音资源。

无线导出：在手机伴侣首次点连接并授权，手表选已保存录音 → 发送到手机。手表显示持久化传输进度，离开页面不取消已经提交的任务。暂停或断开后重新发送同一条可从手机已确认位置继续。显示“手机已完整保存”后，可在手机回听、分享或保存到 Download/Watch6Recorder。

手表原 PCM 与封存账本始终保留，不自动删除。只有校验后的临时 WAV 缓存会在播放器和导出器都已释放后替换；页面重建会恢复缓存与已有导出，不重复生成同一份缓存。手机卸载会删除私有录音，重要音频请保存下载。

## 性能与验证范围

手表界面预建控件与缓存字体，不在渲染中做采音、合并或传输；列表按目录版本缓存。音频准备在原生后台流式处理，不把整条录音加载到 RAM。导出每包最多 2048 字节、单个应用回执在途，防止队列无限增长；恢复时每次只做有上限的读取。手机串行落盘、合并界面刷新，待机不扫描附近蓝牙，不请求云端，也不使用手机麦克风。

校验覆盖真实 Lua 编排与 UI、实际 ARM 采音核心和播放器/传输代码、实际 Java Protocol 与 ArchiveStore，以及 ARM → Java → ARM 的协议闭环。断包、丢回执、重建、CRC 错误、写入失败、取消和退出未确认均有失败路径。最终结果以交付包内 tests/build/package 报告为准。

目前电脑没有检测到 USB 手机，本版本未作新一轮设备安装与验收。扬声器实际路由、末句可听完整性、蓝牙吞吐、HyperOS SDK 授权和息屏存活仍需真机测试；模拟和完整 BIN 解析不替代这些结果。长录音导出不承诺未经测量的秒传速度。
