# 基础功能与验收

## 开发者预览范围

当前版本为 `0.5.3`（手机 0.5.1，连接组件 0.5.0）。BIN 表盘独立完成录音与完整回听；无线导出使用手机 APK、小米运动健康及一次安装的匹配连接身份 RPK。单 RPK 录音验证与独立 BLE 实验已退出当前产品路线。以下能力已纳入源码实现，具体通过情况以本次测试报告为准；没有主机模拟能够替代真实设备验收。

| 能力 | 接受条件 |
|---|---|
| 开始与正式计时 | 明确点击后准备；原生采音确认后进入录音，不把准备时间算作已录音 |
| 暂停和继续 | 使用同一条录音，暂停不误计有效音频时间，控制确认前不提前显示成功 |
| 结束与保存 | 等待尾音、封存与安全退出确认，再允许下一条；与手机和字幕无关 |
| 本地录音列表 | 唯一录音标识，完成/部分/待恢复分开，不把残缺文件显示为完整 |
| 空间保护 | 使用真实剩余空间和保留量，空间不足时安全停止，不静默覆盖旧录音 |
| 状态恢复 | 退出/异常后能发现保留记录；不自动开始录音，不强卸载未知状态模块 |
| 主机 WAV 导出 | 验证连续分段、长度与 CRC，使用固定小块流式合并，保留原文件 |
| 独立存储 | `/data/watch6recorder/`，不访问 VoiceSpace 的录音目录 |
| 固件兼容检查 | 严格匹配已定义指纹；失败时不给开始录音假成功 |
| 手表完整回听 | 校验所有封存分段、尾音和整条 CRC，生成一条标准 WAV 连续播放；支持暂停、继续、停止和全长进度 |
| 手机无线导出 | 复用运动健康已配对设备；断点、重复包、丢回执恢复；逐包及整条 CRC；手机 fsync 后确认保存 |
| 首次设备授权 | 表盘配置的通信身份与连接 RPK、手机 APK 一致；RPK 与 APK 同包名同证书；显式允许 SDK 通信；运动健康已连接不等于本应用接收端已就绪 |
| 后台重连 | 已授权目标逐步退避重连；恢复不反复弹授权；关闭手机接收后不自行重启 |
| 手机使用 | 独立包名、回听和拖动、系统分享、保存 Download；不依赖识别、服务器或电脑配对 |
| 资源互斥 | 回听退出未确认时不开麦；导出源文件关闭未确认时不释放缓存；页面重建只观察已有任务；原生回调不强制卸载 |

## 普通用户正式发布前的实机验收

1. **文件取得出。** 手机上能看到每条录音与传输进度；支持重试、断点续传和完整校验。手机确认文件持久保存后，才允许用户选择清理手表副本。
2. **录音播得完。** 验证手表扬声器和手机回听的完整音频、暂停接缝与最后一句；检查闹钟、来电等音频焦点冲突。
3. **操作看得懂。** 一眼区分准备、录音、暂停、保存与待恢复；录音有明确提示；异常有可执行的恢复路径。
4. **后台稳定。** 真机验证息屏、抬腕、切换表盘、低电量、来电/闹钟打断、连续长录与重新打开；验证手机息屏、蓝牙断开、有限退避和重新授权。不能用永久唤醒锁或高频扫描换取表面稳定。
5. **可维护。** 安装/更新/卸载说明、兼容矩阵、默认隐私保护、故障反馈和升级后旧录音可恢复。

本版覆盖实际采音、播放、分片传输核心、手机持久化及 SDK 回调，读／关闭失败保持缓存和页面重建保持任务所有权也纳入测试。运动健康实际通信、射频吞吐、扬声器和息屏稳定性仍未完成本版实机验收，不能据此宣称装上即可用。

任何导出中断或错误都保留手表原音；手机完整保存也不会自动删除手表副本。录音结束后不等待字幕；本项目没有字幕服务。

## 后续增强

重命名、用户确认删除、按日期整理、剩余可录时长、手机搜索和压缩格式。语音识别和翻译适合作为外部扩展，录音本身应能离线完成。
