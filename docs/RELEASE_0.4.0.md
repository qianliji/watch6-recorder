# 0.4.0-preview：恢复表盘录音与运动健康导出

本版撤下单 RPK 录音验证，停止以普通快应用承担采音。录音、暂停继续、保存、
列表及完整回听统一留在录音 BIN 表盘。独立 BLE 直连实验不进入本版构建。

## 安装内容

| 文件 | 用途 |
|---|---|
| `Watch6-Recorder-0.4.0-preview.bin` | 录音表盘；离线录音与完整回听 |
| `Watch6-Recorder-Phone-0.4.0-preview.apk` | 手机接收、保存、回听、分享及另存下载 |
| `Watch6-Recorder-Identity-0.4.0-preview.rpk` | 运动健康通信身份；只安装一次，日常不用打开 |

连接身份的包名为 `com.watch6.recorder`，versionCode 5，使用本项目证书。
它可更新同包名、versionCode 4 的失败录音验证包；不调用 `system.record`，
不加载原生模块，不替换录音表盘。手机与连接身份需要同一证书。

## 日常流程

1. 打开录音表盘，点开始，等待真实进入录音后计时；可以暂停、继续、结束。
2. 完成封存后即可录下一条，不等待手机联网、字幕或转写。本项目没有转写功能。
3. 需要时在表盘列表完整回听，或选择发送到手机。
4. 无线导出首次需要运动健康配对、匹配连接身份和手机通信授权；之后手机保存
   接收开关、恢复监听并退避重连。系统禁止后台或强制停止仍需要恢复设置。
5. 手机完整落盘并通过校验才显示发送成功；失败和重试保留手表原音。

不新增独立蓝牙扫描、实验连接码或单 RPK 录音测试页。运动健康显示已连接
与本应用接收端就绪分别处理；仅有基础链路不显示录音已成功导出。

## 升级与验证

若安装过旧独立 BLE 实验表盘，应在结束录音、保留文件后完整重启手表一次。
新包不会强制卸载仍持有蓝牙回调或录音文件的旧模块，也不会自动清空原音。

构建仍限定 P65 3.100.043 且精确 AP/audio 指纹匹配，不扩大设备范围。
主机模拟、ARM 测试、APK 核验和表盘完整解析只能证明对应代码与包检查，
本版的真实录音、扬声器、运动健康导出、后台及传输速度仍需实机验收。

源码包不包含失败验证工程、独立 BLE 实验、固件、签名私钥、外部工具包、
SDK JAR 或个人构建设置；预编译手机 APK 包含所需 SDK 编译结果。
