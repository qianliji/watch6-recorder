# 录音与保存修复，交互更新

本次安装组合：表盘 `Watch6-Recorder-0.5.3.bin`、手机 `Watch6-Recorder-Phone-0.5.1.apk`、通信组件继续使用 `Watch6-Recorder-Identity-0.5.0.rpk`。手机和组件同包名、同证书；组件日常无需打开。只更新 BIN 和 APK 即可，保留原有录音。

## 日常操作

- 手表点「开始录音」，进入录音状态后计时；可暂停、继续、结束保存。保存后可回听或发送到手机，右上角「查看录音」进入详情，不需要滑动。
- 「准备下一条」只返回待录状态，不自动开启麦克风。
- 手机「录音」页直接播放、保存到下载或手动分享；底部「连接」处理首次授权和后台设置。首次步骤可展开查看，正常接收不占据录音列表。
- 接收 100% 表示字节已收齐；通过校验和落盘后才显示可播放。保存失败可直接在手机点「完成保存」，不必重传已收到的数据。
- 仅收到部分内容时，从手表发送同一条录音即可续传。原音不会自动删除。

## 本轮修复与证据

- 表盘创建 WAV 缓存补上明确的读写权限，ARM 模拟复现原有 -10，修复后通过。
- 手机实机复现硬链接 `AccessDeniedException`；改为在录音发布锁内原子重命名，仍检查全文件 CRC、WAV 和落盘，不覆盖冲突文件。
- 手机实机以 4 字节合成 PCM 验证最终保存成功；已收齐的 269120 字节实机录音随后成功完成归档。
- 页面重新打开保留失败错误码；保存失败不会仍显示「正在保存」；已收齐但未完成的文件保留可执行的保存入口。

主机测试和浏览器截图不代表实机扬声器全长播放、系统分享、长期息屏和断线恢复已经全部验收。实机照片证明播放曾到 8/16 秒，不把手动停止当作完整播放通过。当前录音已完成手机归档；剩余项目继续以设备结果确认。

## 开源使用

本项目录音、回听、手机保存不使用云端 API 或服务密钥。源码只含本项目代码、公开配置示例和说明，不含个人配置、录音、签名私钥、固件镜像或厂商 SDK。自建版本需按 BUILDING 提供合法外部构建输入，并让 APK 与 RPK 使用自己的匹配证书；不能把预览构建与正式设备兼容验证混为一谈。
