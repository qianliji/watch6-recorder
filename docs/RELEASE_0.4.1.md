# 0.4.1-preview：录音交互与状态恢复改进

本版改善表盘和手机的实际操作流程，保留已使用的运动健康传输路线。
**单 BIN 自有通信身份尚未接入：无线导出仍依赖此前匹配的连接身份组件。
本版是交互验证候选，不是已满足单安装要求的最终成品。**

## 表盘操作

- 首页保留开始录音、录音列表和最近录音；设置集中到右上角。
- 计时依据实际采音状态；暂停、继续、保存和等待退出分别显示。
- 等待回听退出时的待录意图可以取消；重复点击不会延长等待。
- 离开待录意图、回听准备或发送准备页面会取消尚未执行的后续动作。
  已明确开始的原生录音不会因普通页面切换被擅自结束，仍可显式结束保存。
- “准备下一条”只返回待录，不直接打开麦克风；最近录音只打开详情。
- 回听与发送分别显示状态；发送取消等待后台安全退出，之后可以续传或重试。
- 100% 字节进度与手机完整保存确认分别处理，未收到有效确认不显示成功。
- 触控区域至少 52px；用固定 35 个控件、字体和属性缓存减少静止画面工作量。

## 手机操作

- 改为录音库与连接设置两页，完整录音支持回听、保存下载与手动分享。
- 接收不完整的条目显示已安全保存进度，不能提前播放、保存或分享。
- 播放条固定、支持拖动；只有应用可见且正在播放时每 500ms 更新进度。
- 返回后台后停止页面轮询，迟到的原生刷新不会重新启动它。
- 连接状态更新不抢页面、不反复展开帮助；权限设置与运动健康入口可直接打开。
- 设置明确披露当前身份依赖与单表盘尚未完成，不用界面文案掩盖限制。

## 检查与范围

本版增加实际 app/transfer 交互回归、完整 bundle 原生邮箱边界、手机生产 JS
DOM 回放，并检查 360/412 两种宽度的实际 Chromium 页面。表盘布局图来自
实际 Lua 控件模型的 Pillow 近似渲染，不能当作手表截屏。

主机通过不等于真实录音、扬声器、息屏、蓝牙吞吐或无身份组件通信已通过。
本轮没有操作设备或读取个人录音，也没有修改原 VoiceSpace 项目。

候选更新包括 `Watch6-Recorder-0.4.1-preview.bin` 和
`Watch6-Recorder-Phone-0.4.1-preview.apk`。兼容的纯通信身份仍为
`0.4.0-preview`，不需要因界面更新重新安装它。当前交互验证包不额外捆绑
身份 RPK；没有该身份时，离线录音和回听可用，运动健康无线导出尚不成立。

更新前应结束已有录音、保留原文件。若旧原生状态无法确认退出，应完整重启
手表；不要通过强制卸载或清空原音恢复。使用说明和精确兼容范围见源码中的
README、BUILDING 和 COMPATIBILITY。
